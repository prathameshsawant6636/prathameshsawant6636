## 🐰 Smart Rabbit Monitoring & Behavior Detection System

> An AI + IoT based monitoring system designed to continuously observe rabbit activity and provide real-time information about feeding, drinking, movement and resting behavior.

### 🔍 Key Features

* 🤖 **AI-based Object Detection** using YOLO for detecting rabbits, food bowls and water bowls
* 📊 **Behavior Detection** for identifying eating, drinking, resting, active and locomotion states
* 🌡️ **IoT Sensor Integration** using DHT11 and HC-SR04 sensors
* 🚨 **Real-Time Alerts** based on sensor readings and predefined conditions
* 📈 **Automated Monitoring** to reduce the need for continuous manual observation
